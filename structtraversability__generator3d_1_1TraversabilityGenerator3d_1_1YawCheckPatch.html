Detailed Description

One MLS patch prepared for the per-yaw collision checks of one node: the CGAL polyhedron (yaw-INdependent, so built once per node instead of once per yaw sample), its cell centre and top height for the cheap per-yaw prefilters, and the raw patch for the debug drawings.
